# Projektaufgabe Barrista

Entwickle in der Gruppe ein textbasiertes Terminal-Programm namens BARRISTA 88, mit dem eine simulierte Kaffeemaschine ferngesteuert bedient werden kann. Das Programm muss Menüs, Eingaben, Ausgaben, Funktionen, Bedingungen, Arrays und Schleifen enthalten. Jede Teilfunktion soll in eigenen Funktionen umgesetzt werden. Die Programmausgabe erfolgt über das Terminalscript*, Eingaben erfolgen über die bereitgestellte Eingabefunktion.

*) vita-terminal.js wie in demo.html


Pflichtbestandteile
- Mindestens 12 selbst definierte Funktionen
- Mindestens 2 Arrays
- Mindestens 3 if-Abfragen
- Mindestens 1 Schleife
- Mindestens 1 Funktion mit Rückgabewert
- Menüführung mit Benutzereingabe
- Fehlerbehandlung bei ungültigen Eingaben
- Statusanzeige der Kaffeemaschine
- Bezahlfunktion
- Brühfunktion
- Qualitätsbewertung

Erweiterungen
- Reinigungsvorgang
- Statistik: Anzahl gebrühter Getränke
- Umsatzanzeige
- Warnung "Service nötig"
- Spezialgetränke
- Geheimer Wartunsgmodus


Zeitplanung (4 Stunden, evtl mit Erweiterung bei Bedarf):
Phase 1
- Gruppe einteilen
- Teilbereiche festlegen
- Funktionsnamen und gemeinsame Variablen (const, etc) definieren

Phase 2 Grundsystem
- Hauptmenü
- gemeinsame Variablen
- erste Ausgabefunktionen
- erste Eingabe testen

Phase 3 Einzelarbeit in Teilbereichen
- jede Person implementiert ihren Funktionsblock

Phase 4
- Code zusammenbauen
- Fehler suchen
- Menü durchtesten

Phase 5 Feinschliff
- bessere Texte
- Betriebsdaten
- Zusatzfunktionen
- Vorbereitung für Präsentation***

***) Spätere Veröffentlichung wieder als Projekt über den eigenen Webserver, hierzu dann zeitnah besondere Anweisungen zum neuen "vita-Tunnel".
