# Gruppe 5

Verwendetes Tool: Ngrok https://ngrok.com/

So sind wir vorgegangen:
 - Nginx aktiviert
 - in unser WWW folder von Laragon ein folder mit unser HTML dateien eingegeben. 
 - Ngrok installieren 
 - AuthToken in Ngrok mit kommando eingeben: `ngrok config add-authtoken ______`
 - ngrok starten mit kommando `ngrok http 8080`
 - Somit tunneln wir über port 8080
